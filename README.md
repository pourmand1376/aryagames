# بازی حکم شلم قفون

<img src="site/assets/icon.png" alt="" width="96" align="left">

حکم، شلم و قفون؛ بازی‌های ورق اصیل ایرانی، همون‌طور که تو دورهمی‌ها بازی می‌کردیم. با قواعد اصیل و ربات‌هایی که مثل یه یار خوب بازی می‌کنن. بازی کردن رایگانه.

**سایت و دانلود: [aryagames.ir](https://aryagames.ir)**

## دانلود

برای اندروید، ویندوز، مک و لینوکس. نسخهٔ آیفون به‌زودی.

- آخرین نسخه را از [سایت](https://aryagames.ir/#download) یا از [صفحهٔ انتشارها](https://github.com/pourmand1376/aryagames/releases/latest) دانلود کنید.
- هر فایل بعد از انتشار با ویروس‌توتال بررسی می‌شود و نتیجه‌اش کنار همان فایل آمده است.
- [تغییرات هر نسخه](https://aryagames.ir/changelog.html)

## گزارش مشکل یا پیشنهاد

اشکالی در بازی دیدید، قاعده‌ای درست اجرا نشد، یا ربات‌ها حرکت عجیبی کردند؟ لطفاً [اینجا یک Issue باز کنید](https://github.com/pourmand1376/aryagames/issues/new). پیشنهاد هم با کمال میل پذیرفته می‌شود.

برای اینکه زودتر بررسی شود، این‌ها را بنویسید:

- دستگاه و نسخهٔ بازی (مثلاً اندروید، نسخهٔ ۰٫۱۱٫۰)
- کدام بازی (حکم، شلم یا قفون) و چه اتفاقی افتاد
- اگر می‌شود، یک عکس از صفحه

## Hokm Shelem Ghafoon

Hokm, Shelem and Ghafoon, the classic Iranian card games, for Android, Windows, macOS and Linux (iPhone coming soon). The rules are authentic and the bots play like a decent partner. It's free to play.

- **Website and downloads:** [aryagames.ir](https://aryagames.ir), or the [latest release](https://github.com/pourmand1376/aryagames/releases/latest). Every file is scanned on VirusTotal, and its result is shown next to it.
- **Found a bug, a rule that feels wrong, or have an idea?** [Open an issue](https://github.com/pourmand1376/aryagames/issues/new), in Persian or English. Please mention your device, the game version and which game you were playing.

This repository holds the website and the releases; the game's source code is not public. Maintainer notes: [MAINTAINING.md](MAINTAINING.md).
